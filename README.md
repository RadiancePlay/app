# RadiancePlay 🎮

**RadiancePlay** is an Android gaming platform built to run Nintendo Switch games natively on your device. Discover, download, and launch your favorite titles with high-performance native execution and automated deployment.

---

## ⚡ Features

- **Native Switch Execution:** Play supported Switch titles directly and natively on Android hardware.
- **Game Catalog:** Browse, discover, and download titles with fast, optimized downloads.
- **Silent Installation via Shizuku:** Seamless, background package installation without requiring full root access.
- **Environment Diagnostics:** Real-time hardware, API level, and compatibility checks.
- **One-Click Launch:** Centralized library to run and manage installed games instantly.

---

## 🚀 Quick Start

1. **Download & Install:** Grab the latest APK from the [Releases](https://github.com/RadiancePlay/app/releases) section.
2. **Setup Shizuku:** Start the [Shizuku](https://shizuku.rikka.app/) service on your device and grant permission to RadiancePlay for silent installs.
3. **Download & Play:** Open **Games**, select a title, download it, and hit **Launch Game**.
